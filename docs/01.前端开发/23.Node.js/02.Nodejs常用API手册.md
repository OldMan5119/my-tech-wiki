## 📚 Node.js 内置模块速查手册 (v18+ LTS)

### 1️⃣ `fs` - 文件系统操作
> **核心用途**：读写文件、操作目录（**同步/异步**两种方式，**优先用异步**）
```javascript
// 异步读取文件 (推荐)
const fs = require('fs');
fs.readFile('input.txt', 'utf8', (err, data) => {
  if (err) throw err;
  console.log(data); // 输出文件内容
});

// 异步写入文件 (覆盖写入)
fs.writeFile('output.txt', 'Hello Node.js', (err) => {
  if (err) throw err;
  console.log('文件写入成功');
});

// 读取目录
fs.readdir('./logs', (err, files) => {
  if (err) throw err;
  console.log(files); // [ 'app.log', 'error.log' ]
});

// ⚠️ 重要提示：
// - 使用 `fs.promises` 获取 Promise 版 API（更现代）
// - 大文件用 `fs.createReadStream` 避免内存溢出
```

### 2️⃣ `path` - 路径处理
> **核心用途**：跨平台路径拼接、解析（**解决 Windows/macOS/Linux 路径差异**）
```javascript
const path = require('path');

// 拼接路径 (自动处理分隔符)
console.log(path.join('/user', 'local', 'bin')); // '/user/local/bin' (macOS/Linux)
console.log(path.join('C:\\', 'temp', 'file.txt')); // 'C:\temp\file.txt' (Windows)

// 解析路径
const filePath = '/user/local/bin/node';
console.log(path.dirname(filePath));  // '/user/local/bin'
console.log(path.basename(filePath)); // 'node'
console.log(path.extname('index.js')); // '.js'

// 获取绝对路径
console.log(path.resolve('logs', 'app.log')); 
// 输出: /当前工作目录/logs/app.log
```

### 3️⃣ `http` - 创建 HTTP 服务器/客户端
> **核心用途**：构建 Web 服务或发送 HTTP 请求
```javascript
// 创建 HTTP 服务器
const http = require('http');
const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello World\n');
});

server.listen(3000, '127.0.0.1', () => {
  console.log('Server running at http://127.0.0.1:3000/');
});

// 发送 HTTP GET 请求
http.get('http://api.example.com/data', (res) => {
  let data = '';
  res.on('data', chunk => data += chunk);
  res.on('end', () => console.log(data));
});
```

### 4️⃣ `events` - 事件驱动模型
> **核心用途**：实现观察者模式（Node.js 异步基础）
```javascript
const EventEmitter = require('events');
class MyEmitter extends EventEmitter {}

const myEmitter = new MyEmitter();

// 监听事件
myEmitter.on('event', (arg1, arg2) => {
  console.log('触发事件!', arg1, arg2);
});

// 触发事件
myEmitter.emit('event', 'a', 'b'); // 输出: 触发事件! a b

// ⚠️ 关键方法：
// - `.once()`: 只监听一次
// - `.removeListener()`: 移除监听
// - `.setMaxListeners(n)`: 避免内存泄漏
```

### 5️⃣ `stream` - 流式数据处理
> **核心用途**：高效处理大文件/网络数据（**内存友好**）
```javascript
const fs = require('fs');

// 读取流 -> 写入流 (管道操作)
const readStream = fs.createReadStream('big-file.zip');
const writeStream = fs.createWriteStream('copy.zip');

readStream.pipe(writeStream); // 自动处理背压

// 自定义转换流 (示例：转为大写)
const { Transform } = require('stream');
const upperCase = new Transform({
  transform(chunk, encoding, callback) {
    this.push(chunk.toString().toUpperCase());
    callback();
  }
});

process.stdin.pipe(upperCase).pipe(process.stdout);
// 输入 "hello" → 输出 "HELLO"
```

### 6️⃣ `util` - 工具函数集
> **核心用途**：Promise 化、格式化、继承等
```javascript
const util = require('util');
const fs = require('fs');

// 将回调函数转为 Promise (Node.js 8+)
const readFile = util.promisify(fs.readFile);
readFile('input.txt', 'utf8')
  .then(data => console.log(data))
  .catch(err => console.error(err));

// 格式化输出 (类似 console.log)
console.log(util.format('Name: %s, Age: %d', 'Alice', 30)); 
// 输出: Name: Alice, Age: 30
```

### 7️⃣ `child_process` - 子进程管理
> **核心用途**：执行系统命令、运行其他程序
```javascript
const { exec, spawn } = require('child_process');

// 执行简单命令 (获取 stdout)
exec('ls -lh', (error, stdout, stderr) => {
  if (error) console.error(`执行出错: ${error}`);
  console.log(`结果: ${stdout}`);
});

// 流式处理大输出 (推荐用于长时间运行的命令)
const ps = spawn('ps', ['ax']);
ps.stdout.on('data', (data) => {
  console.log(`输出: ${data}`);
});

// 启动新 Node 进程
const node = spawn('node', ['child.js']);
```

### 8️⃣ `crypto` - 加密与哈希
> **核心用途**：数据加密、生成哈希、HMAC
```javascript
const crypto = require('crypto');

// 生成 SHA256 哈希
const hash = crypto.createHash('sha256')
  .update('password123')
  .digest('hex');
console.log(hash); // 'ef92b776...'

// AES-256 加密 (CBC 模式)
const algorithm = 'aes-256-cbc';
const key = crypto.randomBytes(32); // 32 字节密钥
const iv = crypto.randomBytes(16);  // 16 字节 IV

const cipher = crypto.createCipheriv(algorithm, key, iv);
let encrypted = cipher.update('Hello', 'utf8', 'hex');
encrypted += cipher.final('hex');
```

### 9️⃣ `os` - 操作系统信息
> **核心用途**：获取系统硬件/网络信息
```javascript
const os = require('os');

console.log(os.platform());    // 'darwin' (macOS), 'win32', 'linux'
console.log(os.arch());        // 'x64', 'arm64'
console.log(os.totalmem());    // 总内存 (字节)
console.log(os.freemem());     // 空闲内存
console.log(os.cpus());        // CPU 信息数组
console.log(os.networkInterfaces()); // 网络接口
```

### 🔟 `url` - URL 解析与格式化
> **核心用途**：解析和操作 URL 字符串
```javascript
const url = require('url');

// 解析 URL (Node.js v11+ 推荐使用 WHATWG 标准 API)
const myURL = new URL('https://user:pass@sub.example.com:8080/p/a/t/h?query=string#hash');
console.log(myURL.hostname); // 'sub.example.com'
console.log(myURL.pathname); // '/p/a/t/h'
console.log(myURL.searchParams.get('query')); // 'string'

// 旧版解析 (Node.js v6+ 仍支持)
const parsed = url.parse('http://example.com/path?x=1');
console.log(parsed.query); // 'x=1'
```

## 💡 关键使用原则

1. **异步优先**  
   除特殊场景（如启动配置），**永远优先使用异步 API**（如 `fs.readFile` 而非 `fs.readFileSync`）。

2. **错误处理**  
   回调函数中**第一个参数永远检查 `err`**，Promise 用 `.catch()` 或 `try/catch`。

3. **ESM 支持**  
   Node.js v12+ 支持 ES 模块，导入方式：
   ```javascript
   import fs from 'fs'; // 替代 require('fs')
   ```

4. **流式处理大数据**  
   处理 >100MB 文件时，**必须用 `stream`** 避免内存溢出。

5. **官方文档速查**  
   遇到不确定的 API，**第一时间查 [Node.js 官方文档](https://nodejs.org/api/)**（按版本筛选）。
