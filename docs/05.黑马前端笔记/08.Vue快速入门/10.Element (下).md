### 修改

`api/article.js`准备api

```jsx
put /admin/interview/update   data:{ stem,content,id}
```

判断，修改提交：按钮是同一个按钮！区分？是新增下？修改下？

```jsx
submit () {
    this.$refs.form.validate(async valid => {
        if (valid) {
            if (this.title === '添加面经') {
                await createArticle(this.form)
                this.$message.success('添加成功')
                this.current = 1
            }
            if (this.title === '修改面经') {
                const { stem, content, id } = this.form
                await updateArticle({ stem, content, id })
                this.$message.success('修改成功')
            }

            this.initData()
            this.handleClose()
        }
    })
},

```

## yarn-补充

### 介绍

- 快速、可靠、安全的依赖管理工具。和 npm 类似, 都是包管理工具, 可以用于下载包, 就是比npm快；中文官网地址: https://yarn.bootcss.com/



- 下载地址:  https://yarn.bootcss.com/docs/install/#windows-stable 
  - windows - 软件包(在笔记文件夹里) 【**不要安到带中文的路径下,     直接安装在C盘就行  !!!!!**】    win7安装不上：`npm i -g yarn`
  - mac `sudo npm i -g yarn`



### 使用

与npm类似, 可以试试, 新建一个空白文件夹, 执行以下命令尝试一下

```bash
# 1. 初始化, 得到package.json文件(终端路径所在文件夹下)
yarn init

# 2. 添加依赖(下包)
# 命令: yarn add [package]
# 命令: yarn add [package]@[version]
yarn add jquery
yarn add jquery@3.5.1

# 3. 移除包
# 命令: yarn remove [package]
yarn remove jquery
             
# 4. 安装项目全部依赖(一般拿到别人的项目时, 缺少node_modules)          
yarn 
# 会根据当前项目package.json记录的包名和版本, 全部下载到当前工程中

# 5. 全局 npm i xxx -g
# 安装: yarn global add [package]
# 卸载: yarn global remove [package]
# 注意: global一定在add左边     yarn global add @vue/cli 为学习vue做铺垫

```



- yarn在vsc不能使用

```
- 1.c盘 下搜索 powershell.exe
- 2.对其右键 管理员方式打开命令行窗口
- 3.复制命令： Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
- 4.在出现的选项中，win10系统 输入A，（win7系统 输入Y）回车。即可
```
