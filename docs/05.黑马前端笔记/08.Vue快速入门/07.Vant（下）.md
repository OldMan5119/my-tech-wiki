### 统一 token

* 请求数据：

```js
// 响应状态码后台给的
//    4xx：前端有错误！（前端有错误：）
//         404:找不到路径，url地址写错了！
//         400:前端传递参数有问题（参数名错误！）
//         401：Un没有 authorized：身份认证（当前项目：token认证有问题！目前没有带token!）
//    5xx: 后台有错误！和前端没有关系！


// 不用拦截器：需要给请求axios自己加headers;
// 优化：
//      1、发现后面所有的接口都需要加 headers
//      2、能不能放在某个公共地方？请求拦截器去设置公共headers
const res = await this.$axios({
    url: '/interview/query'
    headers: {
      Authorization: localStorage.getItem('h5-token')
    }
})
console.log(res)
```



这个token，需要拼上前缀 `Bearer ` token标识前缀，是接下来所有的请求都需要带上！

```jsx
// 添加请求拦截器

  // 对请求错误做些什么
```

### van-list 加载数据

* onLoad这个函数会初始化执行下； 

```js
methods: {
  async onLoad () {   // 使用组件的立马开始
    const { data } = await getArticles({
      current: this.current,
      sorter: this.sorter
    })
    this.list = data.rows
  }
}
```

* `:immediate-check="false"` 不会立马执行；
  * 滚动下面的时候：需要执行一次；
  * 加载数据。本次加载完成
  * 什么时候就知道数据加载完成？**我们需要在第一次加载数据时候，pageTotal**

```jsx
async onLoad () {
  	this.current++

    const { data } = await getArticles({
        current: this.current,
        sorter: this.sorter
    })
    this.list.push(...data.rows)
    this.loading = false   // 本次请求完成
   
    if (this.current === this.pageTotal) {
        this.finished = true
     }
}

```

### 点击-点赞

* 数据认识：likeFlag 、collectFlag 状态值！

* 点赞：`interview/opt    POST      optType: 1喜欢     2收藏`

```js
like () {
    // 样式切换：likeFlag取对立面！这是组件，不是页面，不会让当前页面再次刷新！
    this.one.likeFlag = !this.one.likeFlag

    // 通知后台：likeFlag毕竟后台数据也得跟着变！自己变！
    this.$axios({
        method: 'POST',
        url: 'interview/opt',
        data: {
            id: this.one.id,
            optType: 1
        }
    })
}
```

* 组件内数量的变化：

```js
// 对当前自己操作的组件内：点赞数量变化！
```
