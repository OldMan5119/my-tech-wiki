## vuex介绍

- 通信方案：数据共享问题
  - 父传子：props所谓形参实参 ； 子传父：$emit发送信号

![image-20210323175925844](/assets6190248375/image-20210323175925844.png)

- vuex是什么：Vuex 是一个专为 Vue.js 应用程序开发的**状态管理模式**。它采用**集中式**存储管理数据，以相应的规则保证状态以一种可预测的方式发生变化

![image-20210601212946879](/assets6190248375/image-20210601212946879.png)

* vuex：大项目
  
  小项目录demo：【父传子：props ； 子传父：$emit     】



* vuex中存什么
  * **多个组件共享状态**，才存储在vuex中（登陆的用户名需要在**首页**, **个人中心**, **结算**页面使用, 用户名存在vuex中）
  * 某个组件中的私有数据，依旧存储在data中（文章详情数据, 只有在文章详情页查看, 在自身data中声明）



* 知道vuex要学习什么  
  * 官网地址: https://vuex.vuejs.org/zh/
  * 安装(固定)
  * 配置项(固定)

| 配置项        | 含义           | 注意                                     |
| ------------- | -------------- | ---------------------------------------- |
| **state**     | 单一状态树     | 类似data                                 |
| **mutations** | 数据管家(同步) | 唯一修改state地方, 让vue调试工具记录变化 |
| actions       | 异步请求       | 要改state需要提交给mutations             |
| getters       | vuex计算属性   | 类似computed                             |
| modules       | 模块拆分       |                                          |

* 单一定义store对象, 里面5个配置项, 在任意组件可以使用

### mutations-【同步】修改数据源

* mutations 类似数据管家, **直接同步修改操作state里的数据**
* state：很多数据公共数据放在state里面，那么数据修改，也是在vuex完成！
* 定义

```javascript
const store  = new Vuex.Store({
    state: {
        count: 100 // 库存
    },
    // 同步：
	mutations: {
		addCount (state, value) { // 负责增加库存的管家
			state.count += value
		},
        subCount (state, value) { // 负责减少库存的管家
            state.count -= value
        },
        setCount (state, value) { // 负责直接修改库存的管家
            state.count = value;
        }
	}
})
```



* AddItem直接用

```vue
<button @click="addFn">库存+1</button>

<script>
export default {
  methods: {
    addFn(){
      this.$store.commit('addCount', 1)
    }
  }
}
</script>
```



* SubItem映射用：推荐写法！

```vue
// 上面的使用方式，写了很长的名字：
<button @click="subCount">库存-1</button>
<button @click="my_subCount">库存-1</button>

<script>
// 需求2: 映射mutations到方法里
// 1. 拿到辅助函数 mapMutations
// 2. mapMutations(['mutations函数名']) ==> 拿到同名方法名的键值对！

import { mapMutations } from 'vuex'
export default {
  methods: {
    ...mapMutations(['subCount']),   // 拿到同名方法名的键值对！
    
    ...mapMutations({my_subCount:'subCount'}),  // 重新命名函数名
  }
}
</script>
```

### actions-【异步】修改数据源

* mutations：同步修改数据
* actions：异步修改数据，为什么要异步修改呢
  * 100：真的放在前端index,js  state里面？
  * 应该：后台的服务器数据库！异步代码！
  * 真的增、减、其实也应该是和服务器通信！

* 定义：异步获取服务器上，初始化数据count数据

```js
const store  = new Vuex.Store({
    // ...省略state和mutations此处
    actions: {
        // 函数名随便起
        getCount(store, num){
            setTimeout(() => { 
                // 1秒后,获取数据 调用reset方法！  模拟：向服务器获取数据
                store.commit('reset', num)
            }, 1000)
        },
        
    }
})
```



* app.vue：异步获取服务器上的数据

```vue
<template>
  <div id="app">
    <h1>根组件</h1>
```

### getters-【计算属性】

* vuex：独立数据！（一切全部独立：本身、操作（同步、异步获取设置）、计算属性）
  * **state(数量列表)、mutations、actions**
  * **getters：用于对state里面数据，相当于组件的计算属性！(总价、总计也放在vuex内部)**

  
  
* 计算属性：某些数据是依赖当前数据计算出来的
  * vuex身上的全局状态-计算属性, 类似于computed
  * getters 依赖于 state中原始数据的变化，并返回计算后的新数据

```js
const store = new Vuex.Store({
    // ...省略其他
    getters: {
        all(state) {
            return state.count * state.price
        }
    }
})
```



* 使用：
  * **计算属性其实也是个变量，只不过该变量依赖其他变量得到的计算结果，使用和state的思路一样**

```js
// 方式1: 组件内 - **直接**使用
this.$store.getters.计算属性名   


// 方式2: 组件内 - **映射**使用
import { mapGetters } from 'vuex'
export default {
	computed: {
        // 2. 把getters里属性映射到原地
      ...mapGetters(['getters里的计算属性名'])
    }   
}
```



* App.vue里使用：

```vue
<h3>
    总价1：{{this.$store.getters.all}}
</h3>

<script>
import { mapGetters } from 'vuex'
export default {
    computed:{
        ...mapGetters({_all:"all"})
		// 总价2：{{_all}}
    },
}
</script>
```

### 定义模块

- 新建store / modules/user.js   两个模块
- 新建store / modules/cart.js

语法: 对象里包含5个核心概念, 只有state变成函数形式

```js
// user.js - 用户模块对象
const userModule = {
    // 开启命名空间，防止多个模块之间, mutations/actions/getters的名字冲突冲突！
    namespaced: true, 
    
    state(){
        return {
            name: "",
            age: 0,
            sex: ''
        }
    },
    mutations: {},
    actions: {},
    getters: {},
    // modules:{},  // 还可以继续设置子模块
}
export default userModule
```



```js
// cart.js - 购物车模块对象
import axios from "axios";

const cartModule = {
  namespaced: true,
  state() {
    return {
      glist: []
    }
  },
  // 直接修改数据
  mutations: {
    setList(state, newList) {
      state.glist = newList
    },
    // 设置每项ck的属性
    ckSet(state, val) {
      state.glist.forEach(item => item.goods_state = val);
    }
  },
  // 异步操作
  actions: {
    // 这里可以写async await语法；
    async getList(store) {
      const res = await axios({ url: "/api/cart" });
      store.commit('setList', res.data.list);
    }
  },

  // 计算属性
  getters: {
    allCount(state) {
      return state.glist.reduce((sum, obj) => {
        if (obj.goods_state === true) { // 选中商品才累加数量
          sum += obj.goods_count;
        }
        return sum;
      }, 0)
    },
    allPrice(state) {
      return state.glist.reduce((sum, obj) => {
        if (obj.goods_state) {
          sum += obj.goods_count * obj.goods_price
        }
        return sum;
      }, 0)
    },
    // 大选的状态
    getCk(state) {
      return state.glist.every(item => item.goods_state == true);
    },
  }
}

export default cartModule
```



### 使用模块

- 把2个模块对象, 引回到store里注册

```js
import cartModule from './modules/cart'
```
