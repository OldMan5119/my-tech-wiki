在使用 Vue CLI 构建项目时，`vue.config.js` 是一个非常重要的配置文件。通过它，我们可以自定义项目的构建行为、开发服务器设置以及生产环境优化等。本文将详细总结 `vue.config.js` 中的常用和实用配置，并结合实际场景进行说明，帮助开发者更好地理解和使用这些功能。

---

## 一、什么是 `vue.config.js`

`vue.config.js` 是 Vue CLI 提供的一个可选配置文件。如果项目根目录下存在该文件，Vue CLI 会自动加载其中的配置。它允许我们覆盖默认的 Webpack 配置，而无需直接修改底层的 Webpack 配置文件。

以下是 `vue.config.js` 的基本结构：

```javascript
module.exports = {
  // 配置选项
};
```

接下来，我们将从以下几个方面详细介绍 `vue.config.js` 的常用配置。

---

## 二、常用配置详解

### 1. **基础路径与输出目录**

#### 配置项：`publicPath` 和 `outputDir`

- **作用**  

  - `publicPath`：指定应用部署的基础路径，默认为 `'/'`。
  - `outputDir`：指定构建后的输出目录，默认为 `'dist'`。

- **示例**  
  如果你的应用部署在子路径（如 `https://example.com/my-app/`），需要设置 `publicPath`：

  ```javascript
  module.exports = {
    publicPath: '/my-app/', // 部署到子路径
    outputDir: 'build',     // 输出目录改为 build
  };
  ```

- **适用场景**  

  - `publicPath`：适用于部署到非根路径的场景。
  - `outputDir`：适用于自定义打包输出目录的需求。

---

### 2. **开发服务器配置**

#### 配置项：`devServer`

- **作用**  
  用于配置开发服务器的行为，例如端口号、代理、热更新等。

- **常用配置**  

  ```javascript
  module.exports = {
    devServer: {
      port: 3000, // 指定开发服务器端口
      open: true, // 自动打开浏览器
      proxy: {
        '/api': {
          target: 'https://api.example.com', // 目标接口地址
          changeOrigin: true,               // 修改请求头中的 host
          pathRewrite: { '^/api': '' },     // 路径重写
        },
      },
    },
  };
  ```

- **适用场景**  

  - 解决开发环境下的跨域问题。
  - 定制开发服务器行为，提升开发效率。

---

### 3. **构建优化配置**

#### 配置项：`productionSourceMap` 和 `css.extract`

- **作用**  

  - `productionSourceMap`：控制是否生成 source map 文件，默认为 `true`。
  - `css.extract`：是否将 CSS 提取到单独的文件中，默认为 `true`。

- **示例**  
  生产环境中关闭 source map 以减少文件大小：

  ```javascript
  module.exports = {
    productionSourceMap: false, // 关闭 source map
    css: {
      extract: true,           // 提取 CSS 到单独文件
    },
  };
  ```

- **适用场景**  

  - `productionSourceMap`：生产环境优化，减少构建体积。
  - `css.extract`：适用于需要将 CSS 单独提取为文件的场景。

---

### 4. **静态资源处理**

#### 配置项：`assetsDir` 和 `filenameHashing`

- **作用**  

  - `assetsDir`：指定静态资源存放的目录，默认为 `'static'`。
  - `filenameHashing`：是否在文件名中添加哈希值，默认为 `true`。

- **示例**  
  修改静态资源目录并启用文件名哈希：

  ```javascript
  module.exports = {
    assetsDir: 'assets',       // 静态资源存放在 assets 目录
    filenameHashing: true,     // 启用文件名哈希
  };
  ```

- **适用场景**  

  - `assetsDir`：适用于需要自定义静态资源目录的场景。
  - `filenameHashing`：适用于需要缓存控制的场景。

---

### 5. **多页面应用配置**

#### 配置项：`pages`

- **作用**  
  用于配置多页面应用（MPA）的入口文件和模板。

- **示例**  
  配置两个页面 `index` 和 `about`：

  ```javascript
  module.exports = {
    pages: {
      index: {
        entry: 'src/main.js',         // 入口文件
        template: 'public/index.html',// 模板文件
        filename: 'index.html',       // 输出文件名
      },
      about: {
        entry: 'src/about/main.js',
        template: 'public/about.html',
        filename: 'about.html',
      },
    },
  };
  ```

- **适用场景**  

  - 多页面应用（MPA）的开发需求。

---

### 6. **CSS 预处理器配置**

#### 配置项：`css.loaderOptions`

- **作用**  
  用于向 CSS 预处理器传递额外的选项。

- **示例**  
  配置全局的 SCSS 变量：

  ```javascript
  module.exports = {
    css: {
      loaderOptions: {
        scss: {
          additionalData: `@import "@/styles/variables.scss";`, // 全局引入变量文件
        },
      },
    },
  };
  ```

- **适用场景**  

  - 需要全局引入样式变量或混入的场景。

---

### 7. **插件与 Webpack 扩展**

#### 配置项：`configureWebpack` 和 `chainWebpack`

- **作用**  

  - `configureWebpack`：直接修改 Webpack 配置。
  - `chainWebpack`：通过链式操作修改 Webpack 配置。

- **示例**  
  使用 `configureWebpack` 添加一个插件：

  ```javascript
  const webpack = require('webpack');
  
  module.exports = {
    configureWebpack: {
      plugins: [
        new webpack.DefinePlugin({
          VERSION: JSON.stringify('1.0.0'),
        }),
      ],
    },
  };
  ```

  使用 `chainWebpack` 修改规则：

  ```javascript
  module.exports = {
    chainWebpack: config => {
      config.module
        .rule('images')
        .use('url-loader')
        .loader('url-loader')
        .tap(options => {
          options.limit = 8192; // 修改图片内联阈值
          return options;
        });
    },
  };
  ```

- **适用场景**  

  - 自定义 Webpack 配置，满足特定需求。

---

### 8. **环境变量配置**

#### 配置项：`env` 文件

- **作用**  
  Vue CLI 支持通过 `.env` 文件定义环境变量，例如：

  - `.env`：所有环境通用的变量。
  - `.env.development`：开发环境专用变量。
  - `.env.production`：生产环境专用变量。

- **示例**  
  在 `.env.development` 中定义变量：

  ```
  VUE_APP_API_URL=https://api.dev.example.com
  ```

  在代码中使用：

  ```javascript
  console.log(process.env.VUE_APP_API_URL);
  ```

- **适用场景**  

  - 环境相关的配置管理。

---

## 三、总结

通过 `vue.config.js`，我们可以灵活地配置 Vue CLI 项目的行为，从基础路径到开发服务器，再到构建优化和 Webpack 扩展，涵盖了前端开发的方方面面。以下是一些关键点的总结：

1. **基础配置**：`publicPath`、`outputDir`、`assetsDir` 等是项目部署和资源管理的基础。
2. **开发体验**：`devServer` 提供了强大的开发工具支持，尤其是代理功能。
3. **构建优化**：`productionSourceMap` 和 `css.extract` 是生产环境优化的重要手段。
4. **高级扩展**：`configureWebpack` 和 `chainWebpack` 提供了对 Webpack 的深度定制能力。
