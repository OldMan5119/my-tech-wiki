`&.btn-primary` 是 Less 中的**父选择器引用**语法。让我详细解释：

## `&` 符号的含义

在 Less 中，`&` 代表**父级选择器**。它允许你在嵌套规则中引用父元素的选择器。

## 具体例子分析

```less
.btn {
    display: inline-block;
    padding: 10px 20px;
    
    // &.btn-primary 等价于 .btn.btn-primary
    &.btn-primary {
        background-color: blue;
        color: white;
    }
    
    // &.btn-danger 等价于 .btn.btn-danger
    &.btn-danger {
        background-color: red;
        color: white;
    }
}
```

## 编译后的 CSS

```css
.btn {
    display: inline-block;
    padding: 10px 20px;
}

/* &.btn-primary 编译后变成 */
.btn.btn-primary {
    background-color: blue;
    color: white;
}

/* &.btn-danger 编译后变成 */
.btn.btn-danger {
    background-color: red;
    color: white;
}
```

## 更多 `&` 的用法示例

### 1. 伪类选择器
```less
.button {
    background: blue;
    
    &:hover {        /* 等价于 .button:hover */
        background: darkblue;
    }
    
    &:active {       /* 等价于 .button:active */
        background: navy;
    }
    
    &:focus {        /* 等价于 .button:focus */
        outline: 2px solid red;
    }
}
```

### 2. 后代选择器对比
```less
.card {
    background: white;
    
    /* 不使用 & - 后代选择器 */
    .title {
        font-size: 20px;
    }
    
    /* 使用 & - 同级类名 */
    &.featured {
        border: 2px solid gold;
    }
}
```

编译后：
```css
.card {
    background: white;
}

/* 后代选择器 */
.card .title {
    font-size: 20px;
}

/* 同级类名（一个元素同时拥有两个类） */
.card.featured {
    border: 2px solid gold;
}
```

### 3. 复杂的嵌套使用
```less
.nav {
    & > li {
        list-style: none;
        
        & > a {
            color: blue;
            
            &:hover {
                color: red;
            }
        }
    }
}
```

编译后：
```css
.nav > li {
    list-style: none;
}

.nav > li > a {
    color: blue;
}

.nav > li > a:hover {
    color: red;
}
```

## 总结

- `&.btn-primary` 表示**当前元素同时拥有父类和子类**
- 在 HTML 中对应：`<button class="btn btn-primary">`
- 这是**类名组合**，不是**层级嵌套**
- `&` 是 Less 提供的语法糖，让嵌套更加灵活和直观
