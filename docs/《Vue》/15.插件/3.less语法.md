# Less 语法详解

Less 是 CSS 的预处理器，扩展了 CSS 的功能。以下是主要语法：

## 1. 变量 (Variables)

```less
// 定义变量
@primary-color: #4CAF50;
@font-size: 14px;
@border-radius: 5px;

// 使用变量
.button {
    background-color: @primary-color;
    font-size: @font-size;
    border-radius: @border-radius;
}
```

## 2. 嵌套 (Nesting)

```less
// Less 嵌套写法
.navbar {
    background: #333;
    
    ul {
        margin: 0;
        padding: 0;
        
        li {
            list-style: none;
            
            a {
                color: white;
                text-decoration: none;
                
                &:hover {
                    color: #4CAF50;
                }
                
                &:visited {
                    color: #ccc;
                }
            }
        }
    }
}
```

## 3. 混合 (Mixins)

```less
// 定义混合
.border-radius(@radius: 5px) {
    border-radius: @radius;
    -webkit-border-radius: @radius;
    -moz-border-radius: @radius;
}

.box-shadow(@x: 0, @y: 0, @blur: 5px, @color: rgba(0,0,0,0.3)) {
    box-shadow: @x @y @blur @color;
}

// 使用混合
.button {
    .border-radius(10px);
    .box-shadow();
}

.card {
    .border-radius(5px);
    .box-shadow(2px, 2px, 10px, rgba(0,0,0,0.2));
}
```

## 4. 函数 (Functions)

```less
@base-color: #4CAF50;

.button {
    background-color: @base-color;
    // 使用内置函数
    border-color: darken(@base-color, 10%);
    color: lighten(@base-color, 20%);
    // 颜色混合
    background: mix(@base-color, #000, 80%);
}
```

## 5. 运算 (Operations)

```less
@base-margin: 10px;
@double-margin: @base-margin * 2;
@half-margin: @base-margin / 2;

.container {
    margin: @double-margin;
    padding: @half-margin;
    width: 100% - (@base-margin * 2);
}
```

## 6. 命名空间和访问符

```less
// 定义命名空间
#bundle() {
    .button {
        display: block;
        border: 1px solid black;
        background-color: #fff;
    }
    
    .tab { 
        color: red;
    }
}

// 使用命名空间
#header a {
    color: orange;
    #bundle > .button; // 引入.button的所有属性
}
```

## 7. 映射 (Maps)

```less
// 定义映射
@colors: {
    primary: #4CAF50;
    secondary: #ff9800;
    danger: #f44336;
};

.button {
    background-color: @colors[primary];
    border-color: @colors[secondary];
}
```

## 8. 条件语句 (Guards)

```less
// 带条件的混合
.mixin(@a) when (lightness(@a) >= 50%) {
    background-color: black;
}

.mixin(@a) when (lightness(@a) < 50%) {
    background-color: white;
}

.mixin(@a) {
    color: @a;
}

.class1 { .mixin(#ddd) } // 背景黑色
.class2 { .mixin(#222) } // 背景白色
```

## 9. 循环 (Loops)

```less
// 生成多个类
.generate-columns(@n, @i: 1) when (@i =< @n) {
    .column-@{i} {
        width: (@i * 100% / @n);
    }
    .generate-columns(@n, (@i + 1));
}

.generate-columns(4);
```

## 10. 导入 (Import)

```less
// 导入其他less文件
@import "variables.less";
@import "mixins.less";
@import "components/buttons.less";

// 导入选项
@import (reference) "variables.less"; // 只导入变量，不输出CSS
@import (inline) "legacy.css"; // 原样导入CSS
```

## 11. 字符串插值和转义

```less
@base-url: "http://example.com";
@image-path: "@{base-url}/images/";

.header {
    background-image: url("@{image-path}header.png");
}

// 转义
.weird-element {
    @{property}: value;
}
```

## 12. 实际应用示例

```less
// 变量定义
@primary-color: #007bff;
@secondary-color: #6c757d;
@success-color: #28a745;

@font-size-base: 16px;
@line-height-base: 1.5;

@border-radius: 0.25rem;
@box-shadow: 0 0.125rem 0.25rem rgba(0,0,0,0.075);

// 混合定义
.button-variant(@color, @background, @border) {
    color: @color;
    background-color: @background;
    border-color: @border;
    
    &:hover {
        color: @color;
        background-color: darken(@background, 10%);
        border-color: darken(@border, 12%);
    }
}

// 样式定义
.btn {
    display: inline-block;
    font-weight: 400;
    text-align: center;
    white-space: nowrap;
    vertical-align: middle;
    border: 1px solid transparent;
    padding: 0.375rem 0.75rem;
    font-size: @font-size-base;
    line-height: @line-height-base;
    border-radius: @border-radius;
    transition: all 0.15s ease-in-out;
    
    // 使用混合
    &.btn-primary {
        .button-variant(#fff, @primary-color, @primary-color);
    }
    
    &.btn-secondary {
        .button-variant(#fff, @secondary-color, @secondary-color);
    }
    
    &.btn-success {
        .button-variant(#fff, @success-color, @success-color);
    }
}
```

Less 的这些特性让 CSS 开发更加模块化、可维护和高效。
